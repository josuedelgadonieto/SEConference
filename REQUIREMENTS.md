# Requerimientos del sistema 
## Requerimientos Funcionales
RF-01. El Sistema Permitira Registrar Asistentes Al Congreso
RF-02. El Sistema Permitira consultar las actividades Diponibles
RF-03. El Sistema Permitira registrar un Asistente a una Actividad
RF-04. El sistema permitira cancelar e registro de un asistente a una actividad

## Requerimientos no Funcionales 
RNF-01. La Iinterfaz debera ser accesible desde un navegador wed
RNF-02. El Sistema debera mantener la informacion debera mantener la informacion del registro de manera persistente
